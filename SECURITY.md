# Güvenlik

## Desteklenen sürümler

Geliştirme aşamasında (`0.x`) güvenlik düzeltmeleri `main` dalına uygulanır.

## Açık bildirme

Güvenlik açığı bulursan **genel issue açma**. GitHub Security Advisories veya repo sahibiyle özel iletişim kullan.

Lütfen şunları ekle:

- Etkilenen sürüm / commit
- Yeniden üretim adımları
- Olası etki (veri, bildirim, cihaz erişimi)

## Gizlilik notu

AlarmApp local-first tasarlanmıştır; varsayılan olarak kullanıcı verisi dış sunucuya gönderilmez. HealthKit verisi (v2) cihaz dışına çıkmamalıdır.
